Petunjuk Instalasi & Penggunaan

Ikuti langkah mudah berikut untuk mulai mengoperasikan aplikasi di sistem komputer sekolah.

01

Cara Instalasi Aplikasi

  • Klik tombol Unduh Installer (.exe) di atas untuk mengunduh berkas aplikasi.
  • Buka file BelSekolah_Setup.exe yang telah diunduh.
  • Jika muncul peringatan Windows SmartScreen, klik More Info lalu pilih Run Anyway.
  • Ikuti instruksi pemasangan di layar hingga proses instalasi selesai.
02

Cara Penggunaan

  • Jalankan aplikasi BelSekolah dari Desktop atau Start Menu.
  • Masuk ke menu Pengaturan Jadwal untuk mengunggah atau mengatur jam bel masuk, istirahat, dan pulang.
  • Pilih nada bel (audio mp3/wav) yang diinginkan untuk setiap jam kegiatan.
  • Biarkan aplikasi tetap berjalan di latar belakang (background) agar bel berbunyi tepat waktu.
